# Combat Update: additions

This folder follows the source collection layout, with the following derived variants added on this branch. Original source images are retained.

- **[R49 · Combat Update - source-faithful 5K resampling](combat-enhanced-and-resampled-5120x2880.png)** — Source resampling. 5120 x 2880 derivative rebuilt from the original 1280 x 720 P49 using bounded sharpening and Lanczos resampling only. Derived images are not original high-resolution releases. See the [full results and quality limits](../../reconstruction/RESULTS.md) for details.
